# 📞 Call Center Dashboard – Power BI

## 📊 Overview
This dashboard provides a complete analysis of call center performance, including call volumes, durations, sentiments, response times, and service quality across different channels and locations.  
It is designed for **interactive exploration** with slicers and enriched insights through **tooltips**.

---

## 📂 Dataset
The dataset contains the following key columns:  
- `Call Timestamp`  
- `Call Center City`  
- `Channel`  
- `Reason`  
- `Sentiment`  
- `Response Time`  
- `Csat Score`  
- `Call Duration`  

---

## 🔧 Features
✅ **KPIs Cards** – Total Calls, Call Duration, Avg Call Duration, and Avg Score  
✅ **Sentiment Analysis** – Track customer sentiment distribution  
✅ **Geographic Analysis** – Calls by State, City, and Call Center locations  
✅ **Performance Tracking** – SLA compliance, response times, and call reasons  
✅ **Channel Analysis** – Distribution of calls across Call-Center, Chatbot, Email, and Web  

---

## 🔍 Slicers (Filters)
The following slicers are included to make the dashboard dynamic:

- **Channel** → Filter calls by service channel (Call Center, Chatbot, Email, Web)  
- **Call Center City** → Analyze performance by city location  
- **Date** → Filter data by time   
- **Reason** → Focus on specific call reasons (Billing, Payments, Service Outage)  

---

## 💡 Tooltip Design
Tooltips are used to add **deeper insights** on hover, without cluttering the main dashboard.  
Two key tooltips were built and enhanced:

### 1. **Tooltip for "No. of Calls by Channel"**
 

👉 This helps compare not just the **volume** of calls but also the **quality and customer satisfaction** per channel.  

---

### 2. **Tooltip for "No. of Calls by Reason"**


👉 This provides insight into which **reasons are time-consuming**, which **channels handle them**, and whether **service levels are met**.  

---

## 🎯 Best Practices Followed
- **Minimal slicers** → Only the most important filters are added (Date, City, Channel, Reason)  
- **Enhanced tooltips** → Extra insights shown on hover instead of adding more visuals  
- **Balanced layout** → KPIs on the left, visuals in the center, slicers on the top

---

## 🚀 How to Use
1. Open the Power BI file (`.pbix`) in **Power BI Desktop**.  
2. Use the slicers to filter data interactively.  
3. Hover over charts to view additional insights via tooltips.  
4. Export or share the dashboard through Power BI Service for collaboration.  

---


✨ With slicers for **exploration** and tooltips for **deep insights**, this dashboard balances **clarity** and **interactivity**.
